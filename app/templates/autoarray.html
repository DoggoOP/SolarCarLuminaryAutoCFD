AutoArray

Upload an `STL`, `OBJ`, `STEP`, or `STP` file and run Shellpower automatically.

`STL/OBJ` uploads are transformed from `X-forward/Z-up` into Shellpower coordinates and filtered to the top-shell `Y-up` band from `0.35 m` to `0.80 m`. AutoArray uses Shellpower defaults of `30°` min angle and `0.035 m` edge margin. `STEP/STP` uses Luminary meshing first, then exports a shellpower mesh.

AutoArray always returns the symmetric layout. Enable this to also run an occlusion-optimized pass for comparison.
